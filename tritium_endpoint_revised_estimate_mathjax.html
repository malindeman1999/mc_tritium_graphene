Tritium Endpoint Mass Estimate with Finite Resolution and Fit-Window Scaling

This note describes the revised spreadsheet-style estimate for a tritium beta endpoint neutrino-mass measurement. It does not address relic neutrino capture. The goal is to estimate the exposure time needed for a specified statistical significance using a simple endpoint-counting model, then apply heuristic corrections for finite energy resolution and for using a fit window wider than the baseline window.

The calculation is intentionally approximate. It is meant to be a transparent back-of-the-envelope model and a sanity check for a Monte Carlo or likelihood fit.

1. Endpoint variable and ideal spectrum

Define the endpoint variable

\[ w = E_0 - E_e \]

where \(E_0\) is the endpoint energy and \(E_e\) is the electron kinetic energy. Near the endpoint, ignoring slowly varying factors, the beta spectrum is approximated as

\[ \frac{dN}{dw} \propto w\sqrt{w^2-m_\nu^2} \]

for \(w>m_\nu\), and zero for \(w \[ \frac{dN}{dw} \propto w^2. \]

2. Effective energy resolution

The calculation uses an effective Gaussian energy resolution \(\sigma_{\rm eff}\), which may include detector resolution and source broadening, such as zero-point motion of tritium bound to graphene, if those effects are approximated as Gaussian.

\[ \sigma_{\rm eff}^2 = \sigma_{\rm det}^2 + \sigma_{\rm zp}^2 + \cdots \]

If a width is given as FWHM, convert to Gaussian sigma using

\[ \sigma = \frac{\mathrm{FWHM}}{2.355}. \]

The effective FWHM is therefore

\[ \mathrm{FWHM}_{\rm eff}=2.355\,\sigma_{\rm eff}. \]

3. Reference window: two FWHM

The revised estimate uses a reference analysis window equal to two effective FWHM below the endpoint:

\[ W_0 = 2\,\mathrm{FWHM}_{\rm eff}. \]

This replaces the earlier practice of choosing an arbitrary narrow endpoint window. A two-FWHM reference window is wide enough to be physically meaningful when resolution is finite, while still close enough to the endpoint to retain mass sensitivity.

4. Perfect-resolution count estimate for the two-FWHM window

First compute the ideal, perfect-energy-resolution count requirement for a window of width \(W_0\). In a perfect-resolution endpoint window \(0 \[ r = \left(1-\frac{m_\nu^2}{W_0^2}\right)^{3/2}. \]

The fractional count deficit is

\[ \delta = 1-r. \]

For a desired significance \(Z\), the required detected counts in the reference window are

\[ \boxed{ N_{\rm perfect}(W_0) = \frac{Z^2}{\delta^2} } \]

or explicitly,

\[ \boxed{ N_{\rm perfect}(W_0) = \frac{Z^2}{ \left[ 1- \left(1-\frac{m_\nu^2}{W_0^2}\right)^{3/2} \right]^2 }. } \]

This is still the idealized perfect-resolution result. The finite-resolution penalty is applied in the next step.

5. Endpoint event rate in the reference window

For source activity \(A\), endpoint energy \(Q\), and total acceptance factor \(f\), the ideal count rate in a window of width \(W_0\) is estimated as

\[ R(W_0) = A\,f \left(\frac{W_0}{Q}\right)^3. \]

Here \(f\) can include geometric efficiency, upward-hemisphere acceptance, retarding-voltage angular acceptance, transport efficiency, and detector efficiency.

For the specific simple model with only upward-going electrons and a retarding voltage equal to one half of the endpoint energy, endpoint electrons pass only for \(\theta<45^\circ\). The angular acceptance relative to all decays is

\[ f_{\rm angular} = \frac{1}{2} \left(1-\cos45^\circ\right) = \frac{1}{2} \left(1-\frac{1}{\sqrt{2}}\right) \approx 0.146. \]

The perfect-resolution exposure time for the two-FWHM reference window is

\[ T_{\rm perfect}(W_0) = \frac{N_{\rm perfect}(W_0)}{R(W_0)}. \]

6. Finite-resolution penalty

Finite energy resolution smears the endpoint shape. The neutrino-mass effect is diluted when the resolution is comparable to or larger than the mass. A simple heuristic penalty is

\[ \boxed{ P_{\rm res} = \left[ 1+ \left(\frac{\sigma_{\rm eff}}{m_\nu}\right)^2 \right]^2. } \]

This factor has the desired limiting behavior:

  • If \(\sigma_{\rm eff}\ll m_\nu\), then \(P_{\rm res}\rightarrow 1\).
  • If \(\sigma_{\rm eff}\gg m_\nu\), then \(P_{\rm res}\propto(\sigma_{\rm eff}/m_\nu)^4\).

The fourth-power scaling appears because the endpoint spectrum is sensitive to \(m_\nu^2\), and detecting a fractional shape distortion statistically requires counts proportional to the inverse square of that fractional distortion.

After applying the finite-resolution penalty, the two-FWHM exposure estimate is

\[ T_{\rm 2FWHM,res} = T_{\rm perfect}(W_0)\,P_{\rm res}. \]

7. Fit-window-width scaling

The two-FWHM window is treated as the reference case. A real endpoint fit may use a wider window below the endpoint. Let the total fit window width be

\[ W = N_{\rm FWHM}\,\mathrm{FWHM}_{\rm eff}, \]

where \(N_{\rm FWHM}\) is the fit-window width expressed in units of effective FWHM.

A crude multi-bin information estimate says that the fraction of asymptotic endpoint-shape information captured by a window of width \(W\) is approximately

\[ F(W)\approx1-\frac{\sigma_{\rm eff}}{W}. \]

In FWHM units, this becomes

\[ F(N_{\rm FWHM}) = 1-\frac{1}{2.355\,N_{\rm FWHM}}. \]

The reference case is \(N_{\rm FWHM}=2\), so

\[ F(2) = 1-\frac{1}{2.355\times2} \approx0.788. \]

The window-scaling factor relative to the two-FWHM reference case is therefore

\[ \boxed{ P_{\rm window} = \frac{F(2)}{F(N_{\rm FWHM})} = \frac{ 1-\frac{1}{2.355\times2} }{ 1-\frac{1}{2.355\,N_{\rm FWHM}} }. } \]

For \(N_{\rm FWHM}=2\), \(P_{\rm window}=1\). For wider windows, \(P_{\rm window}<1\), so the required exposure is slightly reduced. The maximum possible improvement from making the fit window arbitrarily wide is limited:

\[ P_{\rm window}(\infty)=F(2)\approx0.788. \]

So, in this heuristic model, widening beyond two FWHM can reduce exposure by at most about 21%.

8. Final exposure estimate

Combining the pieces gives the final estimate

\[ \boxed{ T_{\rm final} = T_{\rm perfect}(2\,\mathrm{FWHM}_{\rm eff}) \left[ 1+\left(\frac{\sigma_{\rm eff}}{m_\nu}\right)^2 \right]^2 \frac{ 1-\frac{1}{2.355\times2} }{ 1-\frac{1}{2.355\,N_{\rm FWHM}} }. } \]

Equivalently, in terms of counts,

\[ \boxed{ N_{\rm final} = N_{\rm perfect}(2\,\mathrm{FWHM}_{\rm eff}) \,P_{\rm res}\,P_{\rm window}. } \]

Then divide by the endpoint count rate in the two-FWHM reference window to get the exposure time:

\[ T_{\rm final} = \frac{N_{\rm final}}{R(W_0)}. \]

9. Why the wider-window improvement is modest

The endpoint mass information does not grow in proportion to the raw number of beta counts in a wider window. Far below the endpoint, the spectrum has many more counts, but the fractional distortion from neutrino mass is much smaller.

For \(w\gg m_\nu\),

\[ w\sqrt{w^2-m_\nu^2} \approx w^2-\frac{m_\nu^2}{2}. \]

The absolute spectral difference is roughly constant, but the massless spectrum grows as \(w^2\). Therefore, the information density roughly scales like

\[ \frac{(\Delta S)^2}{S_0} \sim \frac{m_\nu^4}{w^2}. \]

This makes the information integral approach a finite limit as the fit window is widened. That is why going from two FWHM to a much wider window helps only modestly in this simple model.

11. Important caveats

  • This is a heuristic statistical estimate, not a full neutrino-mass fit.
  • The two-FWHM reference window is a convention chosen to avoid the unphysical behavior of using a one-sigma window as the baseline.
  • The finite-resolution penalty is approximate. A full model should convolve the beta spectrum with the detector/source response.
  • The fit-window scaling assumes that endpoint energy, normalization, background, and response function are known.
  • In a real experiment, a wider window can help constrain nuisance parameters, but it can also introduce additional systematic sensitivity.
  • For tritiated graphene, zero-point motion and final-state structure should ultimately be represented by a measured or calculated source-response function, not only by a Gaussian width.

12. Monte Carlo version of the same idea

A Monte Carlo can implement this more directly:

  1. Generate true beta energies from \(dN/dw\propto w\sqrt{w^2-m_\nu^2}\).
  2. Apply angular and retarding-voltage acceptance.
  3. Smear measured energy with \(\sigma_{\rm eff}\).
  4. Histogram events over a fit window of \(N_{\rm FWHM}\,\mathrm{FWHM}_{\rm eff}\) below the endpoint.
  5. Compare or fit spectra generated with \(m_\nu=0\) and finite \(m_\nu\).

The spreadsheet estimate above is a compact approximation to that Monte Carlo or likelihood calculation.
